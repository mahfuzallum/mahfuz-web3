# Scoopz রিল অটো-প্রেপ

ভিডিও আপলোড ফেল বা রিজেক্ট হওয়ার টেকনিক্যাল কারণগুলো এই টুল নিজে থেকে খুঁজে বের করে ঠিক করে দেয়। তারপর ভিডিওটা Scoopz-এ আপলোড করার জন্য তৈরি থাকে, সাথে ক্যাপশনও।

## কী কী ঠিক করে

| সমস্যা | ঠিক করার পর |
|---|---|
| HEVC/H.265 (iPhone-এর ডিফল্ট) | H.264 |
| HDR ভিডিও | সাধারণ SDR (রঙ ঠিক রেখে) |
| 10-bit কালার | 8-bit yuv420p |
| 4K রেজোলিউশন | 1080×1920 |
| 60fps | 30fps |
| পাশাপাশি (landscape) বা স্কয়ার ভিডিও | 9:16 ভার্টিক্যাল, দুই পাশে ব্লার ব্যাকগ্রাউন্ড |
| অডিও নেই / অন্য অডিও ফরম্যাট | AAC অডিও |
| MOV/MKV/WEBM | MP4 (faststart) |
| বড় ফাইল (100 MB-এর বেশি) | কম্প্রেস করে ছোট করা |
| মেটাডেটা (লোকেশন ইত্যাদি) | মুছে ফেলা হয় |

## ব্যবহারের নিয়ম

### উপায় ১: GitHub দিয়ে (কম্পিউটার লাগবে না)
1. GitHub-এ এই repo-র `scoopz/inbox/` ফোল্ডারে ভিডিও আপলোড করুন ("Add file → Upload files")।
2. চাইলে একই নামের একটা `.txt` ফাইল দিন ক্যাপশন হিসেবে। যেমন `video1.mp4`-এর জন্য `video1.txt`।
3. Commit করলেই **Actions** ট্যাবে "Scoopz reel prep" নিজে থেকে চলবে।
4. কাজ শেষ হলে নিচে **scoopz-ready** zip ডাউনলোড করুন। এর ভেতরে ঠিক করা ভিডিও, ক্যাপশন আর রিপোর্ট পাবেন।
5. ফোনে Scoopz খুলে ভিডিওটা দিন, ক্যাপশন পেস্ট করুন, তারপর Post চাপুন।

> GitHub-এ এক ফাইল সর্বোচ্চ 100 MB। এর চেয়ে বড় ভিডিওর জন্য উপায় ২ ব্যবহার করুন।

### উপায় ২: নিজের কম্পিউটারে
```bash
# ffmpeg আর Python 3 লাগবে
python3 scoopz/prep.py                 # scoopz/inbox/-এর সব ভিডিও
python3 scoopz/prep.py my_video.mov    # একটা নির্দিষ্ট ভিডিও
```
তৈরি হওয়া ফাইল পাবেন `scoopz/ready/` ফোল্ডারে।

## সেটিংস (`config.json`)
- `hashtags`: প্রতিটা ক্যাপশনের শেষে যে হ্যাশট্যাগগুলো যোগ হবে।
- `default_caption`: `.txt` ফাইল না দিলে এই ক্যাপশন ব্যবহার হবে।
- `max_seconds`: এর চেয়ে লম্বা ভিডিও হলে রিপোর্টে সতর্ক করবে।
- `trim_to_max`: `true` দিলে লম্বা ভিডিও ওই সময় পর্যন্ত কেটে ছোট করবে।
- `max_mb`: ফাইল এর চেয়ে বড় হলে আরো কম্প্রেস করবে।

## যা স্ক্রিপ্ট ধরতে পারে না (নিজে চেক করুন)
এগুলোর কারণে ভিডিও রিজেক্ট হয়, কিন্তু স্ক্রিপ্ট দিয়ে ধরা যায় না:
- কপিরাইট করা গান, মুভি বা টিভির ক্লিপ, অথবা অন্যের ভিডিও।
- TikTok, CapCut বা Instagram-এর ওয়াটারমার্ক।
- Scoopz Community Guidelines-এর বাইরের কন্টেন্ট: নগ্নতা, সহিংসতা, ঘৃণা, বুলিং, আত্মক্ষতি।
- অল্প সময়ে অনেক ভিডিও পোস্ট করা। এতে অ্যাকাউন্ট স্প্যাম হিসেবে ফ্ল্যাগ হতে পারে।

## কেন Post বাটনটা অটোমেটিক না
Scoopz-এর কোনো পাবলিক API বা ওয়েব আপলোডার নেই। আনঅফিশিয়াল বট দিয়ে পোস্ট করলে অ্যাকাউন্ট ব্যান হওয়ার ঝুঁকি আছে। তাই শেষ ধাপটা (Post চাপা) ফোন থেকে নিজে করুন।
